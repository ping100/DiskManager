# Диск-менеджер

Программа для Windows: анализ дисков, умная очистка, перенос файлов и игр между SSD и HDD, давно не используемые
программы, ремонт Windows (SFC/DISM/CHKDSK) и проверка безопасности — с ИИ-советником.

## Скачать

Последняя версия — в разделе **[Releases](../../releases/latest)**:

- `DiskManager.exe` — программа (Python не нужен);
- `DiskManager-portable.zip` — переносная версия для флешки.

Программа сама проверяет обновления: точка в верхнем меню — 🟢 актуальная версия, 🟡 есть обновление, 🔴 нет связи.
